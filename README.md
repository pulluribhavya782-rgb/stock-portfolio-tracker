# 📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that calculates the total investment based on selected stocks and their quantities.

## 📌 About the Project

This project allows users to select stocks from a predefined list, enter the quantity they want to invest in, and calculate the total investment.

## 🚀 Features

- Displays available stocks
- Accepts stock names from the user
- Accepts the quantity of stocks
- Calculates investment for each stock
- Calculates total investment
- Handles unavailable stocks
- Allows the user to finish using `done`

## 🛠️ Technologies Used

- Python
- Dictionary
- Loops
- Conditional statements
- User input

## ▶️ How to Run

2. Open the project folder.
3. Run:
